# 上海房产成交数据

上海市房产网签成交数据的按月归档，以 Markdown 表格形式记录每日成交套数与成交面积。涵盖**二手房**与**一手房**两个市场。

## 数据范围

- 二手房：**自 2025-11 起**，持续更新至当前
- 一手房：**自 2026-10 起**，持续更新至当前

## 文件结构

```
fangdi_data/
├── README.md        # 本说明文件
└── monthly/         # 按月归档，文件名为 YYYY-MM.md
    ├── 2025-11.md
    ├── 2025-12.md
    ├── ...
    └── 2026-10.md
```

每个文件包含四部分（一手房部分仅在该月有数据时生成）：

- **二手房月度汇总**：有数据天数、总成交套数、总成交面积、日均成交套数
- **二手房每日明细**：逐日成交套数与成交面积
- **一手房月度汇总**：同上
- **一手房每日明细**：逐日成交套数与成交面积

## 字段说明

| 字段 | 含义 |
| --- | --- |
| 日期 | 成交日期，格式 `YYYY-MM-DD` |
| 成交套数 | 当日网签成交套数 |
| 成交面积 (㎡) | 当日网签成交总面积 |

## 数据来源

- **二手房**：`fangdi.com.cn` 二手房频道（`old_house`），每日 07:00 自动采集
- **一手房**：`fangdi.com.cn` 首页「今日签约」，每日 22:30 自动采集（滚动数据，隔天即丢）

## 备注

- 月度汇总中的"日均"按**有数据的天数**计算，未剔除周末与节假日的成交波动。
- 二手房成交面积自 2026-05 月底起记录为精确值，此前为约整值。
- 一手房数据来自首页滚动计数器，为当日权威值；若 22:30 采集失败，次日 07:00 由 trade 页面补缺。
- 数据按月追加，新月份在 `monthly/` 下生成对应的 `YYYY-MM.md` 文件。
- 每日 07:05 自动同步至本仓库并推送 GitHub。
