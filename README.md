# 上海二手房成交数据

上海市二手房网签成交数据的按月归档,以 Markdown 表格形式记录每日成交套数与成交面积。

## 数据范围

- 时间跨度:**自 2025-11 起,持续更新至当前**

## 文件结构

```
fangdi_data/
├── README.md        # 本说明文件
└── monthly/         # 按月归档,文件名为 YYYY-MM
    ├── 2025-11.md
    ├── 2025-12.md
    ├── ...
    └── 2026-09.md
```

每个文件包含两部分:

- **月度汇总**:有数据天数、总成交套数、总成交面积、日均成交套数
- **每日明细**:逐日成交套数与成交面积

## 字段说明

| 字段 | 含义 |
| --- | --- |
| 日期 | 成交日期,格式 `YYYY-MM-DD` |
| 成交套数 | 当日二手房网签成交套数 |
| 成交面积 (㎡) | 当日二手房网签成交总面积 |

## 备注

- 月度汇总中的"日均"按**有数据的天数**计算,未剔除周末与节假日的成交波动。
- 成交面积自 2026-05 月底起记录为精确值,此前为约整值。
- 数据按月追加,新月份在 `monthly/` 下生成对应的 `YYYY-MM.md` 文件。
